FalseAlarm settings

Keys are stored in chrome.storage.local (unencrypted, on this device). Use proxy mode for anything beyond a demo. Page text is sent to Google (Gemini) and source summaries to xAI - never on blocklisted/sensitive pages. If scholarly search finds nothing, lookups continue on Wikipedia and DuckDuckGo. If those sources do not address the claim, Grok judges it and names the sources it used.
