# FactLens demo

1. Build the project and load the `dist` directory as an unpacked Chrome
   extension.
2. Open `demo-test-page.html` in a browser tab.
3. Open FactLens and choose **Scan this page**.
4. Click the highlights for:
   - “Humans only use 10% of their brain” — demo assessment: contradicted.
   - “The Great Wall of China is visible from space” — demo assessment:
     contradicted.
   - “Drinking coffee causes cancer” — demo assessment: partially supported.
5. Call out the trust rule: if evidence does not address a claim, use
   “insufficient evidence”; do not call it false.

Demo mode is labeled in the card. For model-generated detection and verdicts,
configure Gemini and Grok keys in Options or use a configured proxy.
