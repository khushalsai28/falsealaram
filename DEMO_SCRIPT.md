# falsealaram demo script

1. **Pitch (15 seconds):** falsealaram highlights questionable claims on the page
   you are already reading and gives you a quick path to scholarly sources.
2. **Open the demo (10 seconds):** Open `dist/demo-test-page.html` in Chrome.
   Keep both Direct-mode model keys empty, then select **Scan this page** from
   the falsealaram toolbar popup.
3. **Show results (25 seconds):** Click each highlighted claim:
   - “Humans only use 10% of their brain” — contradicted.
   - “The Great Wall of China is visible from space” — contradicted.
   - “Drinking coffee causes cancer” — partially supported / needs context.
4. **Trust rule (10 seconds):** Show the source links and Scholar search link.
   Emphasize that falsealaram uses “insufficient evidence” rather than calling a
   claim false when retrieved sources do not address it.

The no-key demo uses built-in example verdicts, not live model judgments.
Scholarly source lookup is attempted live and can be unavailable or incomplete.
